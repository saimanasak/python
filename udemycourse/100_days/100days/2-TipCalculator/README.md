### Tip Calculator

Create a Python program that calculates how much each person should pay when splitting a bill, including a tip.

#### Problem Statement

Ask the user for:

1. The total bill amount.
2. The tip percentage they would like to give (for example, 10%, 12%, or 15%).
3. The number of people sharing the bill.

Calculate the tip, add it to the bill, divide the total evenly among the group, and display the amount each person should pay.

#### Example

```text
Welcome to Tip Calculator...

Enter the total bill(in $): 124.56
Percentage of tip you would like to give (10, 12, or 15): 12
No.of people to split the bill: 7

Each person should pay: $19.93
```

Run the program with:

```bash
python day2_tip_calculator.py
```
