### Band Name Generator

Create a Python program that suggests a band name from two user-provided details.

#### Problem Statement

Ask the user for:

1. The city where they grew up.
2. The name of a pet.

Combine the two responses, separated by a space, and display the result as a possible band name.

#### Example

```text
Welcome to the Band Name Generator...

Enter your city: India
Enter your pet name: Ayra

Your band name could be: India Ayra
```

Run the program with:

```bash
python day1_band_name_generator.py
```
